require: d% :: d%
require: gd :: gd
require: <C-o> :: Ctrl-o
require: <Tab> :: Ctrl-i
ext: ts

A jump moves the cursor far in one go, and vim remembers where it started.

  %        jump to the matching ( ) [ ] { }. If the cursor is not on a
           bracket, % uses the next one on the line
  d%       % is a motion: delete from one bracket through its partner
  gd       go to where the name under the cursor is declared
  Ctrl-o   go back to where you were before the jump
  Ctrl-i   go forward again, the reverse of Ctrl-o

G, gg, {n}G, searches, % and gd are jumps; j, k and w are not. Press Ctrl-o
several times to walk back through older positions.

== Cursor on the ( after "round". % jumps to its closing ): insert ", 2"
== before it, so the line ends with  0), 2);
const net = round(rows.reduce((sum, row) => sum + row.qty * row.price, 0));
-- f(%
-- i, 2<Esc>

== On the return line put the cursor on turbineRetryLimit. gd jumps to where
== it is declared: change 3 to 5. Ctrl-o takes you back: append the missing ;
const turbineRetryLimit = 3;
const turbineBackoffMs = 250;
function turbineDelay(attempt: number) {
  return attempt < turbineRetryLimit ? turbineBackoffMs * attempt : -1
}
