ext: ts

A paragraph is a run of lines with no blank line in it: an import group, a
step inside a function, a test case.

  }    jump to the next blank line      {    jump back to the previous one
  ip   the paragraph's lines            ap   the lines plus the blank line

ip and ap are text objects like iw and aw: every operator takes them, with
the cursor anywhere in the paragraph.

  dap  delete it and its gap            yap  copy it; } then p puts the copy
  >ip  indent it                        cip  replace its lines with new text
  vip  select it, to see what an operator would act on
