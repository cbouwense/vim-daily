title: Indenting: >> << =
keys: >>  <<  3>>  >j  ==  =j
require: >> :: >>
require: <lt><lt> :: <<
require: \d>> :: a count, as in 3>>
require: >\d*j :: >j
require: == :: ==
require: =\d*j :: =j
ext: java

> and < are operators that shift lines one step (2 spaces here). = is the
operator that re-indents lines to fit the braces around them.

  >>   shift this line right       <<   shift it left
  3>>  shift three lines           >j   shift this line and the next
  ==   re-indent this line         =j   re-indent this line and the next

All three take any motion or text object: >i{ shifts the inside of a block
and =i{ re-indents it. In VISUAL mode, select lines with V, then press >, <
or =. A shift repeats with the dot command.
