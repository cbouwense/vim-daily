title: Registers: "a "0 :reg
keys: "ayy  "ap  "Ayy  "0p  :reg
require: "[a-z]y :: "ayy
require: "[a-z][pP] :: "ap
require: "[A-Z]y :: "Ayy
require: "0[pP] :: "0p
require: :reg :: :reg
ext: ts

Every yank and delete lands in a register. Type " and a register name in
front of a command to choose which one it uses:

  "ayy   yank the line into register a       "ap   put register a
  "Ayy   a capital letter appends to register a instead of replacing it
  "0p    put the last yank. Deletes never touch "0, so the yank survives
         any dd, dw or cw you do afterwards
  :reg   list the registers and what they hold

Plain p puts the unnamed register, which every yank AND every delete
overwrites. "+ is the system clipboard, if your vim has clipboard support.
