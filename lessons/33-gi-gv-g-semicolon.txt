title: Back to where you were: gi gv g;
keys: gi  gv  g;  g,
require: gi :: gi
require: gv :: gv
require: g; :: g;
ext: ts

Three ways back to where you were working:

  gi   return to where you last left INSERT mode and carry on inserting
  gv   reselect the last visual selection, to run another command on it
  g;   jump to the position of the last change; press again for the one
       before that. g, steps forward again.

gi is for "I stopped typing to look something up". g; answers "where was I
editing?" and leaves you in NORMAL mode on the change. If the first g;
lands where you already are, press it again.
