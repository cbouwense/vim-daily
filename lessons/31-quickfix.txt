title: Search every file: :vimgrep and quickfix
keys: :vimgrep  :cn  :cp  :copen  :cdo
require: :vim(grep)?\s :: :vimgrep
require: :cn :: :cn
require: :cope?n? :: :copen
require: :cdo\s :: :cdo
ext: ts

Search all files, then walk the matches. :vimgrep fills the quickfix list:

  :vimgrep /TODO/ *.ts      every TODO in the .ts files here (**/*.ts recurses)
  :cn  :cp                  jump to the next / previous match
  :copen  :cclose           show / hide the list; Enter on a line jumps to it
  :cdo s/old/new/ | update  run a command on every match and save each file

Save with :w before :vimgrep or :cn takes you to another file (E37 again).
:Rg from fzf.vim is the interactive cousin. Compiler errors from :make land
in the same list, so :cn and :cp are worth getting used to.
